# javascript-lotto-precourse

# 기능 요구 사항

## 1. 입력

### 로또 구입 금액 입력
- [x]  구입 금액은 1,000원 단위 
- [x]  나누어 떨어지지 않을 경우 예외처리
- [x]  숫자 범위는 1~45

### 당첨 번호 입력
- [x]  번호는 쉼표(,)를 기준으로 구분
- [x]  중복되지 않는 6개 숫자 입력

### 보너스 번호 입력
- [x]  보너스 번호를 입력 
- [x]  당첨 번호와 중복되지 않아야함

## 2. 출력

### 발행한 로또 수량 및 번호 출력
- [x]  `[]개를 구매했습니다` 와 같이 구매한 로또 수와 함께 출력
- [x]  로또 번호는 오름차순으로 정렬하여 출력
- [x]  로또 각각을 리스트 형식으로 반복문 출력

### 당첨 내역 출력
- [x]  당첨번호와 랜덤으로 출력된 로또 번호를 비교

### 수익률 출력
- [x]  `총 수익률은 []% 입니다` 라는 메시지로 출력
- [x]  수익률은 소수점 둘째 자리에서 반올림

## 3. 로또 발행 및 출력

### 로또 발행 수량 계산
- [x]  구입 금액 / 1000 으로 로또 발행 수량 계산
- [x]  1000원으로 나누어 떨어지지 않으면 예외처리

### 로또 번호 생성
- [x]  발행 수량만큼 중복되지 않는 6개의 로또 번호 생성
- [x]  1~45 범위 Random.pickUniqueNumbersInRange 활용

### 발행 결과 출력
- [x]  총 발행 수량을 출력 (`[]개를 준비했습니다.`)
- [x]  각 로또 번호를 오름차순으로 정렬

## 4. 당첨 결과 및 수익률계산

### 당첨 결과 계산
- [x]  발행된 로또와 당첨 번호를 비교하여 일치 개수를 계산.
- [x]  일치 개수에 따라 등수 결정

### 수익률 계산
- [x]  (당첨된 총 상금 / 구입 금액) * 100 으로 계산
- [x]  소수점 첫 째 자리까지 표시 

### 예외 처리
* 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.
* `process.exit()`는 사용하지 않는다.
- [x]  구입 금액이 1,000원 단위 X
- [x]  금액이 0 이하 또는 숫자가 아님
- [x]  로또 번호가 6개가 아님
- [x]  중복된 번호 존재
- [x]  번호가 1~45 범위 내가 아님

## 5. 실행 흐름
1. 구입 금액 입력
2. 로또 자동 발행 및 번호 출력
3. 당첨 번호 입력
4. 보너스 번호 입력
5. 당첨 결과 및 수익률 출력

## 6. 유의 사항
- [x]  indent depth가 3이 넘지 않도록 구현한다.
- [x]  3항 연산자를 쓰지 않는다.
- [x]  함수 또는 메서드가 한 가지 일만 하도록 최대한 작게 만든다.
- [x]  함수 또는 메서드의 길이가 15라인을 넘지 않도록 구현한다
- [x]  else를 지양한다
- [x]  구현한 기능에 대한 단위 테스트를 작성한다.

## 7. 학습 및 도전 포인트
* App.js 중심 흐름 단순화 -> Controller 역할 확실히 분리
* TDD 방식으로 테스트 기반 개발 진행
* 하드코딩 X
* 의미있는 상수명 작명 -> 가독성 향상


## 8. 디렉터리 구조
├── src/
│   ├─ 📄 index.js             # 프로그램 진입점 
│   ├─ 📄 App.js               # 전체 실행 흐름 제어 및 객체 협력 조율 (입력 → 로또발행 → 결과 계산 → 출력)
│   ├─ 📄 LottoMachine.js      # 로또 발행 및 구입 금액 관리 로직 
│   ├─ 📄 Lotto.js             # 로또 객체 정의 (번호, 유효성 검증)
│   ├─ 📄 WinningLotto.js      # 당첨 번호 및 보너스 번호 관리
│   ├─ 📄 LottoResult.js       # 당첨 통계 및 수익률 계산
│   ├─ 📄 InputView.js         # 사용자 입력 처리 (구입 금액, 당첨 번호, 보너스 번호)
│   ├─ 📄 OutputView.js        # 출력 담당 (발행 로또 목록, 당첨 통계, 수익률 표시)
│   ├─ 📄 Validator.js         # 입력값 및 로또 번호 검증 (모든 유효성 검사 담당)
│   ├─ 📄 Constants.js         # 상수 및 에러 메시지 정의 (가격, 범위, 당첨 금액 등)
├── tests/
│   ├─ 📄 LottoTest.js
│   ├─ 📄 WinningLottoTest.js
│   ├─ 📄 LottoResultTest.js
│   ├─ 📄 ApplicationTest.js
│   ├─ 📄 LottoMachineTest.js

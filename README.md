# javascript-lotto-precourse

# 기능 요구 사항

## 1. 입력

### 로또 구입 금액 입력
- [ ] 구입 금액은 1,000원 단위 
- [ ] 나누어 떨어지지 않을 경우 예외처리
- [ ] 숫자 범위는 1~45

### 당첨 번호 입력
- [ ] 번호는 쉼표(,)를 기준으로 구분
- [ ] 중복되지 않는 6개 숫자 입력

### 보너스 번호 입력
- [ ] 보너스 번호를 입력 
- [ ] 당첨 번호와 중복되지 않아야함

## 2. 출력

### 발행한 로또 수량 및 번호 출력
- [ ] `[]개를 구매했습니다` 와 같이 구매한 로또 수와 함께 출력
- [ ] 로또 번호는 오름차순으로 정렬하여 출력
- [ ] 로또 각각을 리스트 형식으로 반복문 출력

### 당첨 내역 출력
- [ ] 당첨번호와 랜덤으로 출력된 로또 번호를 비교

### 수익률 출력
- [ ] `총 수익률은 []% 입니다` 라는 메시지로 출력
- [ ] 수익률은 소수점 둘째 자리에서 반올림

### 예외 처리
- [ ] 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.
- [ ] `process.exit()`는 사용하지 않는다.

### 유의 사항
- [ ] indent depth가 3이 넘지 않도록 구현한다.
- [ ] 3항 연산자를 쓰지 않는다.
- [ ] 함수 또는 메서드가 한 가지 일만 하도록 최대한 작게 만든다.
- [ ] 함수 또는 메서드의 길이가 15라인을 넘지 않도록 구현한다
- [ ] else를 지양한다
- [ ] 구현한 기능에 대한 단위 테스트를 작성한다.
